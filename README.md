# StudioShift

A browser-first image toolkit for music and social creators. Open `index.html` in a modern browser to use it locally.

## Included tools

- Resize with music/social presets, custom dimensions, fit or crop mode, and a canvas background
- Convert to PNG, JPG, or WebP
- Compress JPG and WebP images with a quality control
- Rotate freely or by 90°, plus horizontal and vertical flips
- Enhance brightness, contrast, and saturation
- AI background removal and smart focal-point cropping (optional model download on first use)

All image processing takes place in the browser. No image uploads or account are required. The optional AI model is downloaded on first use and cached by the browser; see `AI-LICENSE-NOTICE.md` before publishing.

## Publishing without a server bill

This folder is a static website: upload its contents to a static host such as Cloudflare Pages, GitHub Pages, or Netlify. Before applying for ad approval, add standalone Privacy Policy, Terms, and Contact pages, and replace placeholder or upcoming tools only when their promised functionality is ready.
